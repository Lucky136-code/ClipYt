# ClipYt — AI Video Studio & Split-Screen Creator

ClipYt is an automated studio that helps creators reformat video content into 9:16 vertical clips with AI subtitles, active facecam detection, and split-screen layouts.

🌐 **Website:** [https://clipyt.vercel.app](https://clipyt.vercel.app/)

## Features
- AI facecam & content auto-framing (60% display / 40% streamer)
- Fast AI subtitles with Hinglish & English transcription
- Climax hook generation
- Instant live stream review and clip creation

## Run Locally
```bash
pip install -r requirements.txt
python run.py
```
Open `http://127.0.0.1:8000` in your browser.
